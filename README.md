# Requirements-to-Test Assistant

Converts a structured product requirement into acceptance criteria, test scenarios, edge cases, a traceability matrix, and automated-test recommendations, using an open-weight LLM with schema validation and an evaluation suite.

Built for the Dayforce AI Innovation Challenge (University).
